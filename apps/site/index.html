Why Cellar

A modern client, without the bloat.

Three things most database tools get wrong, and how Cellar gets them right.

First-class AI, your key

Generate, explain, optimize, and migrate SQL inline, with full schema context. Bring your own Anthropic or OpenAI key. Nothing routes through us.

Maximum density grid

A virtualized grid tuned to 22px rows renders millions of cells without breaking a sweat. Edits stage as a reviewable diff before they ever touch the database.

Every engine, one app

Postgres, MySQL, SQL Server, Azure SQL, and SQLite, each with engine-aware fields, SSH tunneling, and SSL. One muscle memory across all of them.

AI Assistant

Ask in English. Ship real SQL.

Pin tables, queries, and selections as context, then ask. Cellar drafts SQL you can read, run, and insert. Never a black box. Every answer cites the columns and joins it reasoned about.

  • Generate, explain, optimize, and migrate from one bar
  • Read-only mode and a hard spend cap, always on
  • Inline ghost-text completions as you type
Connections

Connect in seconds, safely.

Engine-specific setup with SSH tunnels and SSL/TLS built in. Credentials live in your OS keychain. Never in a config file, never synced anywhere.

  • Test connection with live latency and server version
  • Password or Kerberos auth, per connection
  • Color-coded prod connections so you never slip

Privacy by default

Your data stays on your machine.

Cellar is a local-first desktop app. No account, no cloud sync, no phone-home. The only network calls are to your databases and, if you opt in, your own AI provider.

  • BYO key. Your AI key is stored in the OS keychain and used directly. We never see a token or a prompt.
  • Redaction. Mask column values before they’re ever sent as AI context.
  • Telemetry off. Analytics are opt-in and disabled by default. Inspect exactly what’s stored locally.
