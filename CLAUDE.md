# CLAUDE.md

Follow `AGENTS.md` — it is the canonical guidance for agents in this repo.

## File Size Limit

- No human-authored source, documentation, or configuration file may exceed **800 lines**.
- If a file approaches that size, split it by responsibility before adding more code.
- Generated files, lockfiles, and binary assets are exempt, but never hand-edit generated files — regenerate them through their owning tools.
